Eclipse Launcher is a desktop launcher for Minecraft: Java Edition on Windows, similar to Prism Launcher. It manages separate game instances with Fabric or Quilt, installs mods and packs from Modrinth and CurseForge, and can add Eclipse, my own Fabric mod that changes how the game looks but gives no gameplay advantage. It can also start Horizon, a third-party open-source rewrite of the game, for accounts that own Java Edition. It's a small project, used only by me and my friends.

It needs access so players can sign in with their own Microsoft account, prove they own the game and start it with a valid session. It uses the device code flow with the XboxLive.signin scope, then Xbox Live and the Minecraft services API for login, profile and entitlements. Accounts without the game are refused. Offline accounts can only be added or used once an account that owns the game is on the launcher, and they can't start Horizon. Tokens stay on the player's PC and only go to Microsoft, Xbox Live and Mojang.
