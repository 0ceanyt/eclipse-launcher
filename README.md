# Eclipse Launcher

A desktop launcher for Minecraft: Java Edition on Windows.

- Separate game instances with Fabric or Quilt
- Mods, resource packs and modpacks from Modrinth and CurseForge
- One set of game settings shared across instances
- Optional Eclipse client: a Fabric mod that changes how the game looks, never how it plays
- Can also start Horizon, a third-party open-source rewrite of the game, for accounts that own Java Edition

## Signing in

Players sign in with their own Microsoft account, and the launcher checks that the account owns Minecraft: Java Edition. Login tokens stay on the player's PC and only go to Microsoft, Xbox Live and Mojang.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
